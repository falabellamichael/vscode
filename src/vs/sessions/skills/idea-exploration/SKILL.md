# Idea Exploration

Identify what the user wants to explore. When they specify time, people or materials, treat that as the complete set available for this exercise. Briefly name those constraints in the answer.

Offer a few ways the people involved could use those same resources. Vary the activity, such as telling a story, sketching, sorting or trying a tiny version together. Give each direction a concrete first move and a relevant tradeoff. Honor any direction the user has already ruled out.

Finish with a separate, concrete experiment. Choose one direction and give the first action, the time it takes, and one specific sign to watch for. For example, ask another person to follow a sketch without help and notice where they hesitate. Make the test possible with the stated resources. The user can choose or combine the options afterward.
