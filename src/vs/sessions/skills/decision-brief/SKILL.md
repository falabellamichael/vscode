# Decision Brief

State the choice in the user's terms. Start with the options, constraints, and evidence already supplied. Use the criteria that could change the choice, such as a deadline, a cost ceiling, or the ability to reverse course. Use the user's stated priorities to resolve tradeoffs.

Keep each stated benefit and drawback with the option it belongs to. Compare the options on the same criteria. Preserve quantities, dates and the direction of each difference. Use the user's original wording for the decisive fact when a paraphrase could change its meaning. A condition or time period only applies where the source places it.

For a short recommendation, name the choice and cite the specific fact that meets the user's highest priority. Then say what the user gives up by choosing it, using the alternative's strongest advantage and any stated difference. Respect the requested length. Mention an uncertainty when it could change the choice. If the user wants a neutral brief, leave the decision open.
